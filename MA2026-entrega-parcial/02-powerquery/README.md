# 02-powerquery — Etapa 2 (Power Query)

`cheiU_02_PowerQuery.xlsx` com todas as consultas Power Query. Elas leem os brutos de `01-excel/dados-brutos/` e os cadastros de `cheiU_01_Excel.xlsx` por parâmetros derivados de `CaminhoRepo`.

| Pasta | Conteúdo |
|---|---|
| `scripts_m/` | Código M de cada consulta, `<Consulta>.pq`, primeira linha `// <Consulta>` (fonte da verdade) |
| `dados_limpos/` | Tabelas de saída em CSV UTF-8 |
| `evidencias/` | Prints do painel de consultas, das etapas aplicadas e da conferência |
| `scripts/` | Automação do Excel via COM (E0.7) |

Plano: `docs/plano/etapa-2-powerquery.md`. Exigências do professor: `docs/plano/referencia-professor.md`.
